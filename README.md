# ⚛️ 量子力学インタラクティブ学習アプリ

サーバー・ビルドツール・外部API・課金一切なしの、**完全無料**で動く量子力学の学習用Webアプリです。
純粋な HTML / CSS / JavaScript (ES Modules) のみで実装しており、ブラウザだけで完結します。

## 収録トピック

1. **無限井戸型ポテンシャル (箱の中の粒子)** — 量子数と箱の幅を変えて波動関数・確率密度・エネルギー準位を確認
2. **量子調和振動子** — エルミート多項式による波動関数とポテンシャル、等間隔なエネルギー準位
3. **量子トンネル効果** — split-step Fourier法によるガウス波束の時間発展シミュレーション + 解析的な透過率/反射率
4. **水素原子の軌道 (s, p, d軌道)** — 動径分布関数と電子密度の断面図(ヒートマップ)
5. **二重スリット実験** — 干渉パターンの理論値と、1粒子ずつ発射して模様が浮かび上がる様子のシミュレーション

## ローカルで動かす

外部依存なしの静的サイトなので、リポジトリを開いて `index.html` をブラウザで開くだけで動作します。
`fetch`/ES Modules の関係でファイルを直接開くとブラウザによっては制限がある場合、簡易サーバーで確認してください:

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 無料でホスティングする方法

このリポジトリは静的ファイルのみなので、以下のような無料ホスティングにそのままデプロイできます。

- **GitHub Pages**: リポジトリの Settings → Pages で `main` ブランチを指定するだけ (追加費用なし)
- **Netlify / Vercel / Cloudflare Pages**: リポジトリを連携するだけでデプロイ可能 (無料枠で十分)

## 技術メモ

- 描画はすべて `<canvas>` への手書き実装 (グラフ・ヒートマップとも自作、チャートライブラリ不使用)
- 特殊関数 (エルミート多項式・ラゲール陪多項式・ルジャンドル陪多項式) は再帰式で自前実装 (`js/utils/math.js`)
- トンネル効果のシミュレーションは、時間発展 (split-step Fourier法) 用に自作の反復FFT (`js/utils/math.js` の `fft`) を使用
- 単位系は特に断りがない限り ħ = m = 1 の自然単位 (水素原子モジュールのみボーア半径 a₀ = 1 の原子単位系)

## ディレクトリ構成

```
index.html
css/style.css
js/main.js               タブ切り替えコントローラ
js/utils/math.js         特殊関数・FFTなどの数値計算
js/utils/plot.js         canvas描画ヘルパー (折れ線グラフ・ヒートマップ)
js/modules/*.js          各トピックごとのUI・シミュレーションロジック
```
